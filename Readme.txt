Веб-приложение, реализующее распределенную очередь сообщений с доступом по протоколу HTTP. Пользователи (клиенты) могут отправлять сообщения в очередь, получать их и обрабатывать с использованием HTTP-запросов. Система состоит из серверной части на платформе Laravel (PHP), которая управляет очередями, распределяет задачи между воркерами и обеспечивает хранение состояний, и клиентской части на платформе Next.js (React, TypeScript), предоставляющей интерфейс для мониторинга и управления очередями. Обмен данными между клиентами и сервером происходит по протоколу HTTP.
Серверная часть реализует логику распределенной очереди: принимает сообщения от клиентов через API, помещает их в очередь с поддержкой приоритетов и отложенной обработки, обеспечивает гарантированную доставку и обработку сообщений распределенными воркерами. Для хранения информации о сообщениях, очередях и результатах обработки используется база данных PostgreSQL. В качестве брокера для распределенного хранения очередей может использоваться Redis.
Клиентская часть обеспечивает веб-интерфейс для создания очередей, отправки тестовых сообщений, мониторинга статуса обработки (успешно, в очереди, ошибка) и просмотра статистики. Текст пояснительной записки оформляется в соответствии со стандартом СТП 01—2024.
